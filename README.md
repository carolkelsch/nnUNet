# nnUNet implementations for thesis
This code originates from nnUNet master version from commit 6ed222f on March 4th.

New classes and utils were implemented focusing on airways and lung lobes segmentation, This includes losses such as [clDice](https://github.com/jocpae/clDice) and two boundary losses inspired by [nnSAM](https://github.com/Kent0n-Li/nnSAM).

The original nnUNet repo can be found [here](https://github.com/MIC-DKFZ/nnUNet).
